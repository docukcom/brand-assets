## The name

Write the name as **DOC**, in capitals. The website is doc.uk.com.

## Using the logo

- Use the files as they are. Do not redraw, recolour, stretch, rotate or add effects to the logo.
- Use `logo.svg` on light backgrounds and `logo-on-dark.svg` on dark backgrounds.
- Leave clear space around the logo.
- Do not use the logo in a way that suggests DOC endorses you, or that DOC is part of the NHS.

Need something else? Email [info@doc.uk.com](mailto:info@doc.uk.com).
